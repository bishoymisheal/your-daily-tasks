# 🌟 Your Daily Tasks — لوحة الإنتاجية الذكية (Productivity Dashboard)

تطبيق ويب عصري ومتكامل لإدارة المهام اليومية، متابعة العادات، وتقنية بومودورو للتركيز، مبني بالكامل بتقنيات الويب الأساسية (HTML5, CSS3, Vanilla JavaScript) بدون أي مكتبات خارجية ثقيلة، مع حفظ تلقائي محلي للبيانات (`localStorage`).

## ✨ المميزات الرئيسية (Key Features)

### 1. 🕒 ساعة رقمية حية متطورة
- نظام **12 ساعة** صباحًا ومساءً (AM / PM) باللغة العربية.
- عرض الثواني المتحركة، التاريخ الميلادي واليوم.
- تصميم رقمي نيون جذاب بتدرج لوني فخم.

### 2. 📑 هيكل متعدد الصفحات (3 صفحات داخلية تفاعلية)
- **الصفحة الرئيسية (Home):** نظرة عامة شاملة، إحصائيات سريعة، مؤقت بومودورو، واقتباس تحفيزي يومي متجدد وملاحظات سريعة.
- **صفحة الروتين اليومي (Daily Routine & Habits):** متابعة العادات اليومية مع عداد الالتزام (Streak) وحلقات الإنجاز الدائرية (Progress Rings).
- **صفحة المهام اليومية (Daily Tasks):** إدارة المهام، تصنيف حسب الأولوية والتصنيف، الفلترة حسب الحالة، مع واجهة مستخدم سريعة وسلسة.

### 3. ⏱️ مؤقت بومودورو للتركيز (Pomodoro Timer)
- جلسات عمل واستراحة (25 دقيقة عمل / 5 دقائق راحة / 15 دقيقة راحة طويلة).
- مؤشر زمني دائري متحرك وأصوات تنبيه عند انتهاء الجلسة.
- إمكانية التبديل بين الأوضاع بسهولة وإعادة التعيين.

### 4. 🌙 ثيم مزدوج (Dark Mode / Light Mode)
- **الوضع الليلي (Dark Mode):** تصميم زجاجي عصري (Glassmorphism) مع ألوان نيون وخلفيات ضبابية مريحة جداً للعين.
- **الوضع النهاري (Light Mode):** مظهر نظيف وساطع مع تباين ألوان عالي ومريح.
- حفظ اختيار الثيم تلقائياً في التخزين المحلي للمتصفح.

### 5. 💾 حفظ تلقائي دون إنترنت (Offline & LocalStorage)
- جميع المهام، العادات، والملاحظات والإعدادات تُحفظ فورياً في متصفحك.
- لا يتطلب إنشاء حساب أو وجود اتصال بالإنترنت.

## 🚀 التقنيات المستخدمة (Tech Stack)

- **HTML5:** بنية دلالية (Semantic HTML) وتوافقية كاملة مع محركات البحث ومعايير إمكانية الوصول.
- **CSS3:** شبكة Bento Grid، وتصميم مرن (Flexbox & CSS Grid)، مع متغيرات ألوان CSS متقدمة وتأثيرات Glassmorphism و Micro-animations.
- **Vanilla JavaScript (ES6+):** بنية معيارية ومنظمة لإدارة الحالة (State Management) والـ LocalStorage بدون أطر عمل إضافية.
- **Google Fonts:** خط **Outfit** للأرقام والإنجليزية، وخط **Tajawal / Cairo** للغة العربية.

## 💻 طريقة التشغيل محلياً (Run Locally)

1. قم بنسخ المستودع (Clone the repository):
```bash
git clone https://github.com/bishoymisheal/your-daily-tasks.git
```
2. افتح المجلد:
```bash
cd your-daily-tasks
```
3. افتح ملف `index.html` في أي متصفح ويب مباشرة!
